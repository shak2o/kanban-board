# Трекер задач: доска Канбан

Небольшое одностраничное приложение для управления задачами: три колонки («К выполнению», «В работе», «Готово»), добавление и удаление задач, перемещение между колонками кнопками и перетаскиванием мышью. Состояние сохраняется в `localStorage`, задачи можно импортировать из JSON по ссылке.

Проект написан как учебно-практический и показывает работу с React, TypeScript, DOM-событиями, `localStorage`, `fetch` и тестированием.

## Возможности

- Добавление задачи с проверкой: пустое название и название длиннее 200 символов отклоняются с понятным сообщением
- Перемещение задачи между колонками кнопками ← и → или перетаскиванием мышью (HTML5 Drag and Drop)
- Удаление задачи
- Сохранение всех задач в `localStorage` и восстановление после перезагрузки страницы
- Импорт задач из JSON по URL через `fetch` с состояниями загрузки, ошибки и успеха
- Валидация импортируемых данных: при первой ошибке импорт останавливается и сообщает, какая запись неверна

## Стек

- TypeScript (строгий режим)
- React 18
- Vite — сборка и dev-сервер
- Vitest и Testing Library — тесты
- CSS без сторонних UI-библиотек

## Запуск

Требуется Node.js LTS (проверено на версии 22).

```bash
npm install
npm run dev
```

Открой в браузере адрес, который появится в терминале, обычно `http://localhost:5173/`.

Остальные команды:

```bash
npm test          # запуск тестов один раз
npm run test:watch
npm run typecheck # проверка типов без сборки
npm run build     # проверка типов и production-сборка в папку dist
npm run preview   # запуск собранной версии на http://localhost:4173/
```

## Импорт задач

В поле «Импорт задач из JSON по ссылке» по умолчанию стоит `/sample-tasks.json`, файл лежит в папке `public`. Ссылка может указывать на любой JSON-файл того же происхождения или на сервер, который отдаёт заголовки CORS.

Формат данных — массив объектов:

```json
[
  { "title": "Изучить доску задач", "status": "todo" },
  { "title": "Добавить свою первую задачу", "status": "in-progress" },
  { "title": "Открыть проект в браузере", "status": "done" }
]
```

- `title` — обязательное поле, строка до 200 символов
- `status` — необязательное, одно из `todo`, `in-progress`, `done`; по умолчанию `todo`

Импортированные задачи добавляются к уже существующим.

## Структура проекта

```
src/
  main.tsx                  точка входа
  App.tsx                   состояние приложения и связка компонентов
  styles.css
  components/
    AddTaskForm.tsx         форма добавления задачи
    ImportTasksForm.tsx     импорт по ссылке
    Board.tsx               три колонки
    Column.tsx              колонка с поддержкой drop
    TaskCard.tsx            карточка задачи
  domain/
    tasks.ts                модель задачи и чистые функции над списком
    tasks.test.ts
    storage.ts              чтение и запись localStorage с валидацией
    storage.test.ts
    import.ts               валидация данных и fetch
    import.test.ts
  App.test.tsx              сценарии пользователя
public/
  sample-tasks.json
```

Бизнес-логика (`src/domain`) не зависит от React и тестируется без браузера. Компоненты только отображают состояние и передают действия наверх.

## Тесты

```bash
npm test
```

Сейчас 39 тестов в четырёх файлах:
- `tasks.test.ts` — добавление, перемещение, удаление, группировка по колонкам
- `storage.test.ts` — сохранение и загрузка, повреждённые данные, ошибка доступа к хранилищу
- `import.test.ts` — валидация записей и обработка ошибок `fetch`
- `App.test.tsx` — добавление, ошибка пустого названия, перемещение, удаление, сохранение, восстановление и импорт через подменённый `fetch`

## Известные ограничения

- Перетаскивание мышью автоматически не тестируется: в jsdom нет полноценного `DataTransfer`. Проверяется вручную.
- Нативный Drag and Drop плохо работает на сенсорных экранах. Для телефонов и планшетов перенос кнопками ← и → остаётся основным способом.
- Задачи хранятся только в браузере одного устройства. Синхронизации нет.
- Нельзя редактировать название задачи и менять порядок карточек внутри колонки.
- Нет отмены действий.
- Бэкенда нет: импорт работает с файлом или внешним JSON-ресурсом.

## Возможные направления развития

- Редактирование названия и сортировка внутри колонки
- Перетаскивание через Pointer Events, чтобы работало на сенсорных экранах
- E2E-тесты в браузере (Playwright), в том числе для перетаскивания
- Экспорт задач в JSON в том же формате, что и импорт
- Backend на Spring Boot с REST API и PostgreSQL вместо `localStorage`
